# Intersection Counter

A small web app that counts road intersections within a user-drawn rectangle on a map, using OpenStreetMap data via the Overpass API.

## Features

- Draw a rectangle on the map
- Count road intersections inside (nodes shared by 2+ road ways)
- Compute intersection density (intersections per km²)
- 100% client-side — no backend

## Built with

- [Leaflet](https://leafletjs.com/) for the map
- [Leaflet.draw](https://github.com/Leaflet/Leaflet.draw) for the rectangle tool
- [Overpass API](https://overpass-api.de/) for OSM data
- OpenStreetMap tiles
